# Tipper

SwiftUI foundation screen for a one-page iPhone interface with five equal vertical sections:

1. Tipper up/down momentary controls
2. Tarp off/on arrow controls
3. Scales display (`00.000`) plus Tare button
4. Door 1 momentary open/close controls
5. Door 2 momentary open/close controls

Includes a top-right settings menu with per-section Bluetooth pairing placeholders.
